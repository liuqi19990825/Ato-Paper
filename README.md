# Ato Paper

一款为 Typecho 1.3.0 制作的纸张风个人博客主题，由 Ato 与 Codex 共同构建。当前版本为 0.3.1。

## 当前功能

- 纸张质感首页与阅读型文章页
- 深色模式与本地偏好记忆
- 分类、标签、作者和搜索归档
- Typecho 原生评论与嵌套回复
- 独立“近况时间轴”页面
- 后台可配置首页文案、插图、社交链接、备案信息和时间轴内容
- 响应式手机布局、键盘焦点与减少动效支持
- 文章副标题、题图和题图说明自定义字段
- 可在后台开关的原生 PJAX 页面加载、纸张过渡与失败自动回退
- 首页补充文字支持手动填写或接入一言 API，并在失败时显示手动备用文字
- 页脚结束语与右侧补充文字可在后台独立设置
- 页头标题图标提供小花、樱花、星芒、爱心、四叶草、蝴蝶结与音符选项
- 每篇文章可以独立开启右侧章节目录或正文首字放大，默认均关闭
- 首页侧栏“关于”区域可跳转到独立页面，社交与 RSS 链接使用更易读的字号和点击区域

## 安装

1. 将完整的 `AtoPaper` 文件夹上传到 Typecho 的 `/usr/themes/` 目录。
2. 在 Typecho 后台进入“控制台 → 外观”，启用 `Ato Paper`。
3. 进入“设置外观”填写首页内容、社交链接和备案号。

## 创建近况页面

1. 在后台新建独立页面，标题填写“最近在做什么”，缩略名填写 `now`。
2. 展开高级选项，将自定义模板选为“近况时间轴”。
3. 发布页面后，把页面地址填写到主题设置中的“近况页面地址”。默认地址是 `now.html`。
4. 在主题设置的“近况时间轴”中维护内容；每行一条，格式如下：

```text
2026-08-05|博客|给这个小世界重新铺一层纸|整理歌单，也在认真把博客装修得更舒服一点。
```

请把最新一条放在最上方，首页便签会自动读取它。

## 文章题图

编辑文章时展开高级选项，可以填写：

- `首页“今天的片段”`：填写后首页优先显示；留空时自动截取正文前 62 个字符
- `文章副标题`
- `文章题图 URL`
- `题图说明`
- `文章章节目录`：手动开启后读取正文中的二级、三级标题，在宽屏右侧显示
- `正文首字放大`：手动开启后只放大当前文章第一个段落的首字

这些字段都可以留空，不影响正常发布。

## PJAX 页面加载

PJAX 默认开启，可以在“设置外观 → PJAX 无刷新加载”中随时关闭。站内普通链接会使用纸张过渡；评论提交、搜索、下载、站外链接和 Typecho 后台地址仍使用标准跳转。加载失败时主题会自动退回完整页面刷新。

如果以后安装的插件包含必须整页执行的脚本，可以先在主题设置中关闭 PJAX；插件开发者也可以为特定链接添加 `data-no-pjax` 属性，或监听 `ato:page-ready` 与 `ato:pjax:complete` 事件重新初始化页面功能。

## 兼容性

- 面向 Typecho 1.3.0 开发
- PHP 7.4 或更高版本
- 推荐使用较新的 Chrome、Edge、Firefox 或 Safari
